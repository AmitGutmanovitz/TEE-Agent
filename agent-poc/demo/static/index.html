    What each test proves

    • The agent's code: the agent runs in genuine Intel TDX hardware, and it booted exactly the published, pinned container.
    • The prompt: the exact system prompt and question that went in, signed by a key that only exists inside the agent's TEE.
    • The model: the LLM ran on a TDX machine with an NVIDIA H100 in confidential mode, confirmed by NVIDIA's attestation service.
    • The answer: a receipt signed by Phala's attested gateway covers the exact request and response bytes, unmodified.
    • Encryption: the prompt was encrypted end to end to the gateway enclave. The report shows the one-time keys, and re-checks the math.

    Not proven: whether the answer is correct, or which exact model weights were loaded. The checks here run in a verifier service inside the same confidential VM. For fully independent verification, run verify.py on your own machine.
